[Aliases](https://github.com/yantonov/uv-aliases/blob/master/config.toml) for [uv](https://github.com/astral-sh/uv)

### Usage
1. clone and add this repository to the front of PATH
2. build alias [alias](http://github.com/yantonov/alias) (or use the available distribution)
   name it as uv and put it into this repository (binary file has already ignored inside this repository)
3. alternative to (2), use 
```bash
    install.sh
```
this script downloads latest alias distribution for the current operating system names it in appropriate way and puts to the current directory
